Sobre o Projeto

O Citizen Assist AI é um assistente digital introdutório criado para facilitar o acesso de cidadãos a informações úteis do cotidiano, como serviços, documentos, direitos e orientações comunitárias. A aplicação organiza um conjunto verificável de informações, recebe perguntas ou escolhas do usuário e apresenta respostas claras com referências, possuindo navegação simples e sem coletar dados pessoais desnecessários.
O projeto atende ao desafio "CitizenTech", que propõe o desenvolvimento de soluções capazes de melhorar a vida das pessoas nas cidades, no campo ou nas comunidades.
